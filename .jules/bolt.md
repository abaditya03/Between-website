## 2024-06-18 - Avoid Redundant Zero-Length Canvas Strokes in Reciprocal Particle Networks
**Learning:** When calculating reciprocal distance networks for particle physics or networks (where pairs i and j are compared), initializing the inner loop at `j = i` instead of `j = i + 1` causes redundant calculations. Worse, when distance is calculated, it evaluates to 0, which satisfies distance threshold checks (`dist < 120`) and triggers actual zero-length canvas draw calls (`moveTo`, `lineTo`, `stroke`) per particle, per frame, adding invisible rendering overhead and lowering framerate.
**Action:** Always start reciprocal pair inner loops with `j = i + 1` to strictly skip self-comparisons and duplicate calculations, specifically eliminating invisible sub-renderings when the algorithm naively accepts `0` as `< threshold`.
