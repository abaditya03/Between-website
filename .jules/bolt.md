## 2024-05-24 - Inner loop collision optimization in Canvas ParticleNetwork
**Learning:** In a canvas particle network calculating distances between particles, starting the inner loop at `j = i` instead of `j = i + 1` evaluates reciprocal pairs twice (redundant) and compares particles to themselves. Because a self-comparison results in a distance of 0, which satisfies distance threshold checks (e.g., `dist < 120`), it leads to redundant math and unintended zero-length canvas draw calls (`ctx.lineTo` with `dx=0` and `dy=0`). This creates unnecessary overhead per frame.
**Action:** When implementing distance calculations for pairs in a collection, always initialize the inner loop at `j = i + 1` to skip reciprocal pairs and self-comparisons, avoiding redundant calculations and draw calls.
