## 2024-09-24 - Canvas Particle Optimization
**Learning:** Found an O(N^2) loop calculating particle connections in `ParticleNetwork`. The inner loop started at `j = i`, which resulted in each particle being compared to itself. This meant distance was exactly 0, and since `0 < 120`, it invoked unnecessary canvas calls (beginPath, moveTo, lineTo, stroke) to draw lines of length 0 over every particle. Also, computing `Math.sqrt()` for every pair before checking distance is extremely expensive.
**Action:** When optimizing canvas particle loops, start the inner loop at `j = i + 1` to skip self-comparison, and use squared distances (`distSq < 120*120`) before performing `Math.sqrt()`. This reduces `Math.sqrt()` calls from O(N^2) to only the lines actually drawn, and saves exactly N draw calls of 0-length lines per frame.
