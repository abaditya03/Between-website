## 2024-05-17 - Prevent N redundant zero-distance canvas draw calls
**Learning:** In the `ParticleNetwork` ambient animation canvas loop, iterating the inner loop `for (let j = i; j < particles.length; j++)` compares each particle to *itself*. This results in a distance calculation of exactly `0`, which is naturally `< 120`. Consequently, an invisible stroke of 0 length is drawn on the canvas `particles.length` times per frame.
**Action:** When calculating interactions between particles in a network where reciprocal pairs are already skipped (`j = i`), always initialize the inner loop at `j = i + 1` instead to skip self-comparisons. This avoids N redundant calculations per frame and prevents unexpected zero-length canvas draw calls when `dist = 0` satisfies distance thresholds.
