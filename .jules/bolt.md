## 2024-05-19 - [Isolating Parallax Hooks to Prevent Cascading Re-renders]
**Learning:** In a large React component tree (like `App` in `index.html`), placing a high-frequency event hook (such as `useScrollParallax()` which updates state on every scroll tick) at the very top level forces the *entire application* to unnecessarily re-render on every scroll event. This causes a massive performance bottleneck, especially when the application contains many complex and unmemoized child components (e.g., `AuraPrivacyEngine`, `NeuralInsightDemo`).
**Action:** Always isolate state that updates frequently (like scroll position, mouse coordinates, or animation frames) into the smallest possible dedicated wrapper component (e.g., `<HeroParallax>`). This scopes the re-render strictly to the DOM nodes that actually depend on that state, bypassing the rest of the application tree.
