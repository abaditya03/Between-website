
## 2024-11-20 - Redundant Zero-Length Canvas Draw Calls in O(N^2) Particle Distance Checks
**Learning:** In the `ParticleNetwork` component's O(N^2) nested loop calculating inter-particle distances, initializing the inner loop with `j = i` (instead of `j = i + 1`) forces a distance calculation between a particle and itself. Since the distance is 0, it trivially satisfies the `< 120` threshold. This causes the Canvas API to execute a zero-length line drawing command (`ctx.moveTo(x, y)` to `ctx.lineTo(x, y)`) for every single particle on every single animation frame, incurring unnecessary performance overhead alongside the N redundant math calculations.
**Action:** When calculating interactions between particles in a network where reciprocal pairs are already skipped, initialize the inner loop at `j = i + 1` to skip self-comparisons. This avoids N redundant calculations per frame and prevents unexpected zero-length canvas draw calls when `dist = 0` satisfies distance thresholds.
