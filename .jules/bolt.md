## 2026-06-22 - Optimizing Reciprocal Pair Calculations in Canvas Networks
**Learning:** When calculating interactions (like distances or drawing lines) between all pairs of particles in a network, checking `for (let j = i; ...)` still includes self-comparisons (`j == i`) where the distance is 0. If the distance threshold for drawing is `dist < 120`, `dist = 0` satisfies this condition, resulting in N redundant zero-length draw calls (`ctx.moveTo(x,y); ctx.lineTo(x,y); ctx.stroke();`) every single frame.
**Action:** When implementing interactions in a particle network where reciprocal pairs are already skipped (`j = i`), initialize the inner loop at `j = i + 1` to skip self-comparisons. This avoids redundant zero-length canvas draw calls and computationally expensive but unnecessary `Math.sqrt(0)` calculations per frame.
