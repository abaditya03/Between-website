## 2024-05-24 - Canvas Drawing Redundant Particle Self-Comparisons
**Learning:** In canvas particle network animations, calculating line distances using nested loops starting at `j = i` results in redundant self-comparisons where `dist = 0`. Since `0 < 120` is true, this leads to an unnecessary 0-length canvas `stroke()` call for every particle on every frame, which adds noticeable performance overhead. Modern JS engine optimizations make redundant `Math.sqrt` fast, but the canvas context API calls are expensive.
**Action:** When implementing interacting particles or nodes that form networks based on distance, always ensure the inner comparison loop starts at `j = i + 1` to skip self-comparisons and prevent redundant 0-length stroke drawing paths, thereby dramatically reducing draw calls and canvas API overhead.
