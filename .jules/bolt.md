## 2025-05-18 - Avoid self-comparison in n-body interactive particle simulations
**Learning:** In the `ParticleNetwork` component, when calculating interactions between particles where reciprocal pairs are already skipped (`j = i`), initializing the inner loop at `j = i` instead of `j = i + 1` causes N redundant self-comparisons per frame. This forces `dist = 0` calculations, which satisfies the distance thresholds and results in unexpected zero-length canvas draw calls.
**Action:** When calculating interactions between particles in a network where reciprocal pairs are already skipped (`j = i`), always initialize the inner loop at `j = i + 1` to skip self-comparisons. This avoids N redundant calculations per frame and prevents unexpected zero-length canvas draw calls when `dist = 0` satisfies distance thresholds.
