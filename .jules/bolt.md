## 2024-06-11 - Hidden performance cost of zero-length canvas draw calls
**Learning:** In the `ParticleNetwork` component, nested loops calculating interactions between reciprocal pairs (`j = i`) were doing more than just redundant math. When an element is compared against itself, the distance (`dist`) is exactly 0. Because `dist < 120` is true, this triggers `ctx.stroke()` for a zero-length line. These silent, zero-length draw calls added significant overhead to the Canvas rendering pipeline (avoided ~70 per frame).
**Action:** When calculating interactions between particles or elements in a list where reciprocal pairs are skipped, initialize the inner loop at `j = i + 1` to bypass both self-comparisons and redundant operations, preventing invisible performance drains like zero-length drawing operations.
