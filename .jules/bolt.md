## 2024-05-23 - Avoid premature Math.sqrt in high-frequency React Canvas loops\n**Learning:** High-frequency canvas animation loops (`requestAnimationFrame`) can become severely constrained by evaluating `Math.sqrt` on every iteration, particularly O(n^2) particle network updates. Modifying the loop to `j = i + 1` removed reciprocal iterations and self-comparisons entirely. A squared distance check acting as an early guard (`distSq < 14400`) before running `Math.sqrt` reduced execution time by >70% locally.\n**Action:** For performance-obsessed operations in high-frequency rendering loops, replace immediate radial distance comparisons involving `Math.sqrt` with squared equivalents (`x^2 + y^2 < r^2`) to fast-path exclusions, especially in N-body or particle interaction calculations.
