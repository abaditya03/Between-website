## 2024-05-24 - Avoiding Redundant Canvas Draw Calls in Particle Networks
**Learning:** In canvas-based particle network rendering where interactions between particles are calculated, initializing the inner loop at `j = i` instead of `j = i + 1` results in calculating self-interaction where distance is 0. If `dist < threshold` is the only check, this satisfies the condition and unnecessarily issues `ctx.stroke()` calls (e.g., 70 redundant calls for 70 particles per frame).
**Action:** When calculating interactions between elements in a collection, always check if reciprocal pairs are already skipped and if self-comparisons are necessary. Initialize inner loops correctly (e.g., `j = i + 1`) to eliminate O(N) redundant zero-length canvas draw calls and unnecessary mathematical operations.
