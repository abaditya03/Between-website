## 2024-05-24 - [Avoid Redundant Canvas Draw Calls in Particle Networks]
**Learning:** In canvas-based particle network animations, calculating line distances using nested loops where the inner loop starts at `j = i` (instead of `j = i + 1`) results in self-comparisons. Because the distance between a particle and itself is 0, which is always less than the distance threshold (e.g., 120), this triggers a redundant, zero-length `stroke()` call for every single particle on every single frame. This means 70 particles will cause 70 invisible draw calls per frame, significantly impacting rendering performance.
**Action:** When implementing or reviewing `O(n^2)` particle network interactions, always ensure the inner loop starts at `i + 1` to skip self-comparisons and avoid executing costly canvas rendering functions for zero-length paths.
