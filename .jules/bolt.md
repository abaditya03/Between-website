## 2024-07-09 - [Preventing Redundant Self-Comparison in O(n²) Distance Checks]
**Learning:** In unoptimized nested loops for calculating distances between pairs of entities (like a canvas particle network where N=70), initializing the inner loop at `j = i` checks each particle against itself. This always results in `dist = 0`, which is typically smaller than the distance threshold (e.g. `dist < 120`). Consequently, the drawing logic incorrectly fires, issuing N redundant, 0-length draw calls (`ctx.stroke()`) every single frame (e.g. 70 x 60fps = 4200 wasted calls/sec), wasting CPU cycles for visual output that doesn't exist.
**Action:** Always start inner loops for reciprocal pair interactions at `j = i + 1` to skip self-comparisons and save iterations/operations, especially inside high-frequency `requestAnimationFrame` loops.
